
# 📊 InvestGuide

InvestGuide is a web-based investment platform prototype that aims to bring multiple financial instruments into a single application.

The goal of the project is **not to provide direct financial advice**, but to build an integrated system where users can:

- track and trade different assets such as gold, EUR, USD, and Bitcoin  
- follow AI-supported trend predictions
- share opinions and discuss investment ideas with other users  

The project focuses on system design, data management, and building a multi-technology full-stack application.

## ✨ Features
- Unified platform for multiple assets:
  - Gold  
  - Euro / Dollar  
  - Bitcoin  
- Basic buy & sell simulation  
- AI-supported trend tracking (prototype level)  
- User interaction and idea sharing module  
- Centralized investment dashboard

## 🛠️ Tech Stack
- Python  
- C#  
- HTML / CSS  
- MySQL  
- MongoDB  
- Other supporting libraries and tools

## 📌 Motivation
This project was created to practice:

- full-stack application design  
- working with both SQL and NoSQL databases  
- integrating multiple technologies in a single system  
- designing a scalable financial platform architecture  

## ✔︎ Project Status
- **This project was developed as a university course project by a team of students.**
